# Steam 游戏产品分析

本项目基于 Steam 游戏历史数据，对不同年份的游戏数量、价格分布、好评率、游玩时长、类型结构、关键词趋势和推荐游戏进行分析，并制作了一个可离线打开的交互式 HTML 可视化页面。

项目目标不是简单展示图表，而是从产品分析视角观察 Steam 市场变化：哪些类型长期占据供给主流，玩家偏好如何变化，价格带是否影响评价表现，以及哪些产品特征更适合后续商业化落地。

## 项目内容

## 如何查看

直接双击 `index.html` 即可在浏览器中打开最终可视化页面。页面不依赖联网，可以离线查看。

页面支持按年份切换，核心模块包括：

- 年度 KPI 指标卡片
- 游戏类型分布
- 年度关键词趋势
- 价格分档与好评率
- 推荐游戏 TOP 5
- 各类型代表游戏
- 跨年度趋势变化
- 趋势结论与商业化建议

## 数据处理流程

1. 使用 `data/timeline_data.json` 作为源数据。
2. 通过 `scripts/clean_data_for_tableau.py` 清洗和标准化数据。
3. 将嵌套 JSON 拆分为年度指标、类型分布、价格分档、词云、推荐游戏等平表结构。
4. 修正价格分档口径，将原项目中容易误解的“免费-5”统一处理为 `0-5`，并单独保留 `Free` 占位，避免将免费游戏与低价付费游戏混淆。
5. 使用 `sql/export_tableau_csv.sql` 对清洗后的 SQLite 数据进行筛选，并导出可用于 Tableau 或 HTML 的 CSV 表。
6. 最终用 `index.html` 进行可视化展示。

## 主要分析结论

从年度趋势看，Steam 游戏数量在近年持续增长，市场供给明显扩张；价格中位数整体上移，说明新品定价和内容体量都有提高。

类型结构上，Action、Adventure、Casual、Indie 等仍是数量最多的主流方向，但关键词中 `create`、`city`、`skills`、`survival`、`team` 等词频较高，说明玩家偏好正在向创造建造、城市经营、生存合作、技能成长和长期可玩内容集中。

从商业化角度看，不建议只追随热门类型堆量，而应优先选择“高活跃玩法 + 清晰差异化标签 + 合理价格带”的组合。中低价位、可持续更新、带合作或建造成长机制的游戏，更容易在高竞争环境中形成长期评价和口碑优势。
